| Field | Value |

## Artifacts this feature touches
- `pipeline/feature2/memory_pipeline/write_memory.js` — dependency-free validated writer using the approved CLI contract.
- `pipeline/feature2/memory_pipeline/read_memory.js` — dependency-free exact-namespace reader with the approved 4-characters-per-token FIFO ceiling.
- `pipeline/feature2/memory_pipeline/memory_common.js` — shared namespace, type-tag, record-schema, and candidate-validation constants and helpers used by both CLIs.
- `pipeline/feature2/memory_pipeline/memory_store.json` — seeded persistent JSON array containing the Feature 1 45-minute travel-buffer fact.
- `pipeline/feature2/memory_pipeline/memory_pipeline.test.js` — dependency-free Node.js standard-library verification covering CLI behavior, schema/provenance, retention, malformed input, persistence, namespace isolation, deterministic reads, seeded retrieval, token approximation, and FIFO budget enforcement.
- Tests use a temporary `MEMORY_STORE_PATH` copy of the seed and remove it after execution; the committed `memory_store.json` is not mutated by the test suite.

## Human approvals
- Approved write CLI: `node write_memory.js "<payload>" "<source_task>" "<type_tag>"`.
- Approved read CLI: `node read_memory.js`.
- Approved record shape: each store entry is an object with `timestamp` (ISO-8601), `source_task`, `type_tag`, and `payload`; the payload contains the validated `repo:branch:env` namespace and memory content.
- Approved token approximation: 4 characters equal 1 token, with a hard 500-token read ceiling.
- Approved over-budget behavior: drop the oldest matching records first, FIFO, until the returned JSON is under the ceiling. Relevance ranking and summarization are deferred production enhancements.
- Approved namespace: `ServiceForge:feature2-parts:dev`; `MEMORY_NAMESPACE` may select another exact `repo:branch:env` namespace for isolated invocations.
- Implementation is limited to the three memory-pipeline artifacts listed above; backend and frontend code remain untouched.
